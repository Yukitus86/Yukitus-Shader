# Yukitus Shader – project notes

Iris shader pack (OptiFine format) for Minecraft Java 1.21.11 – 26.x, owned by Yukitus86.
The owner speaks German and prefers short, structured answers with bullet points.
The look is inspired by Complementary Shaders, but all code is original: never copy code from other
shader packs, and credit published techniques in README → Credits.

## Layout
- `shaders/lib/settings.glsl` – every user option (`#define NAME value // [values]`) and engine consts (shadowMapResolution, …)
- `shaders/lib/` – common (uniforms, helpers, packing, Halton TAA jitter), colors (time of day), sky, clouds, fog,
  lighting, materials (integrated PBR + labPBR), shadows, water, waving, reflections (SSR), bloom_tiles
- `shaders/program/*.glsl` – one file per pass; stage chosen by `#ifdef VSH` / `FSH`, variants by defines (`GB_TERRAIN`, …)
- `shaders/world0|world-1|world1/` – **generated** wrappers (`tools/generate.py`), never edit by hand; the Nether has no shadow pass
- `shaders/block.properties`, `shaders/textures/noise.png` – generated by `tools/generate.py`; `shaders/lang/*.lang` – generated by `tools/lang.py`
- `shaders/shaders.properties` – menu screens, sliders, profiles (POTATO … ULTRA), blend overrides, custom uniform `snowiness`, `texture.noise`
- `dist/` – release zip (`tools/build.py`, includes README and LICENSE)

## Pipeline (forward lighting)
| Pass | What it does |
|---|---|
| shadow | distorted shadow map (`distortShadowClip`, z × 0.25); shadowcolor0 = glass tint / water caustics, stored × 0.5 |
| gbuffers opaque (`gbuffers_solid`) | full lighting per fragment → colortex0, normal + lightmap → colortex1, material → colortex2 |
| deferred | procedural sky + volumetric clouds on sky pixels, SSAO weighted by aoWeight, fog for opaque geometry |
| gbuffers translucent | glass etc. lit + fogged and blended into colortex0; water only writes data (colortex3/5), alpha 0 in WATER_STYLE 0 |
| composite | water refraction / absorption / foam / reflection / sun specular, glass and opaque SSR, underwater fog |
| composite1 | volumetric light (shadow map raymarch) |
| composite2 | TAA (YCoCg variance clipping, Catmull-Rom history) + auto exposure from the previous frame's smallest bloom tile |
| composite3–5 | bloom mip tiles in colortex7, separable blur |
| final | sharpening, optional DoF / motion blur, bloom, exposure, tonemap (ACES / Lottes / Reinhard-Jodie), grading, vignette, dither |

Buffers:
- colortex0 RGBA16F scene color
- colortex1 RGBA16 = (normal.xy octahedral, pack2x8(block light, sky light), 1)
- colortex2 RGBA16 = (matClass / 255, smoothness, pack2x8(f0, aoWeight), 1)
- colortex3 RGBA8 translucent = (sun visibility, smoothness, f0, 1)
- colortex5 RGBA16 translucent = (normal.xy, pack2x8(type / 4, sky light), 1); type 1 = glass, 2 = water
- colortex6 RGBA16F TAA history, exposure in alpha (not cleared)
- colortex7 RGBA16F bloom tiles (not cleared)

Data buffers are always written with alpha 1 so blending cannot corrupt them. `depth < 0.56` means hand.

Block ids (`mc_Entity` / `blockEntityId`, see `tools/generate.py`): 10001 plants (bottom anchored), 10002 upper half of tall plants,
10003 leaves, 10004 vines, 10005 crops, 10006 lily pad, 10007 other foliage, 10010 water, 10011 ice, 10012 glass, 10013 slime/honey,
10014 nether portal, 10020 lava, 10021 fire, 10022 light blocks, 10023 torches/lanterns, 10024 ores, 10025 magma, 10026 amethyst,
10030 metal, 10031 polished stone, 10032 gems, 10033 obsidian, 10040 snow, 10041 porous (no mirror puddles), 10050 redstone,

## Workflow
- After editing: `python3 tools/generate.py` (programs / blocks changed), `python3 tools/lang.py` (options changed), `python3 tools/validate.py`
- New option: add it to `settings.glsl`, to a `screen.*` line in `shaders.properties` (numbers also to `sliders`), and to `tools/lang.py`
- Headless tests (Mesa llvmpipe, needs no GPU):
  - `bash tools/harness/setup.sh` – installs deps, builds the GLX helper, starts Xvfb `:99` (run again after a container restart)
  - `python3 tools/harness/iris_emu.py compile [--set NAME=on|off|value]` – compiles + links all 80 programs of all dimensions
  - `python3 tools/harness/option_matrix.py` – every option flipped / every enum value (about 2 minutes)
  - `python3 tools/harness/iris_emu.py render --times 0.2,0.485,0.75 [--rain 1] [--water 1] [--dim world-1] [--camx X --camy Y --camz Z --yaw D --pitch D --tag NAME --out DIR]`
    writes PNGs (default `/tmp/claude-0/renders`); `tools/harness/combo.py OUT.png IN...` makes a grid. Always look at the images.
- Build the zip: `python3 tools/build.py` (version in `VERSION`)

## Git / GitHub
- `main` is protected by a ruleset (no deletion, no force push); work on a branch, open a PR, merge
- A cloud session cannot push tags (HTTP 403) and cannot change repository settings (the owner does that, e.g. via local Claude Code + `gh`)
- Release: bump `VERSION` in `tools/build.py`, add `.github/release-notes/vX.Y.Z.md`, merge, then run the `release.yml` workflow
  (workflow_dispatch with input `tag`); it validates, builds, creates the tag and publishes the release with the zip
- Current release: v1.0.1 (repository is public)

## Status and open points
- Only tested in the emulator so far, not in real Minecraft. Uncertain Iris details: particle and hand order relative to
  deferred (handled both ways), no `gbuffers_line` program (falls back to basic)
- Tuning constants (exposure `0.24 / avgLum` clamped to [0.35, 2.4], sun intensity 3.4, volumetric light density, sky colors)
  were chosen by looking at emulator renders; retune from in-game screenshots
- Ideas: colored block light, Distant Horizons support, lens flare
